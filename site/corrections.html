WEST BENGAL / CORRECTIONS

Keep the evidence accountable.

Corrections, source updates and uncertainty are part of the research process.

Give the record ID, disputed field, reason and a supporting public source URL. Explain the relevant context briefly. Do not include unsupported allegations, harassment, discriminatory material, private documents or unnecessary personal information.

GitHub submission access

Use the controlled GitHub Issue Forms below. They become public when the maintainer makes the repository public; until then, repository access is required. Do not submit private information. No submission is published automatically.

Repository access information

Submissions never publish automatically. Maintainers may suspend a record while examining its source and record a neutral revision or dispute status. No fixed response time is promised. Do not use public Issues for sensitive correspondence.

Suggest a public source

Provide its URL, publisher, publication date if known, a neutral event description and a short evidence span. A suggestion is a discovery lead, not an accepted record. Anonymous claims, forwards and unsupported screenshots cannot become published evidence.
