Public dataset

The JSON download contains the dataset version, generation time, record count and context notice.

Download JSON ↧Download CSV ↧CSV metadata ↧Download aggregate counts ↧

JSON is the authoritative structured view. CSV is a convenience export with a disclaimer and dataset metadata repeated on each row. Its companion metadata file describes the same generated export. The private evaluation dataset contains reviewed real-source records; synthetic fixtures and the design prototype are excluded.

Counts describe records in this tracker, not official inspection totals, prevalence, compliance, risk, wrongdoing or group-level behavior. Inclusion is not a finding of wrongdoing. Source verification is not independent proof of the underlying event.

Use with attribution and care

Retain source links, record IDs, dates, verification status and contextual disclaimer when sharing. Inspect original source context and any later record updates. Third-party article content is not relicensed by this project. No blanket data ownership or licensing claim is made.

Pending candidates, rejected material and private review history are excluded from public downloads. Suspended stable record URLs show minimal status notices; their claims are excluded from the evidence register.
